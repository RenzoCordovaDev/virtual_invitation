# src/content/

Contenido real del evento (nombres, fecha, direcciones, dress code, mesa de
regalos, canción) derivado de `informacion_base.md`, tipado para usarse desde
los feature modules. Ningún componente debe tener texto del evento
hardcodeado — siempre importado desde acá. Se actualiza a mano cuando cambia
`informacion_base.md` (no hay sincronización automática en v1 — ver
`docs/PROJECT.md` sección 7).
